# Salma Portfolio

A clean engineering portfolio built from scratch with React, TypeScript, Vite, and React Router.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Before deploying

1. Add `public/Salma-Nurfauziah-CV.pdf` if you want the Resume button to work.
2. Replace placeholder GitHub/demo links.
3. Add project screenshots under `public/projects/`.
4. Update project data in `src/data/projects.ts`.
5. Deploy to Vercel.

## Notes

The portfolio intentionally avoids exposing confidential company information. The production workflow section describes responsibilities and architecture at a high level.
